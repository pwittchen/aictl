Privacy Policy

Short version: the aictl software has no telemetry and sends your data only where you point it. The website uses lightweight analytics to count visits.

Last updated: October 4, 2026

Who is responsible

aictl and the aictl.app website are run by Piotr Wittchen, an individual developer, who is the data controller for the purposes of this policy. Contact: piotr@wittchen.io.

The software (CLI, desktop app, server)

aictl runs on your own machine. It has no telemetry, no usage tracking, and no crash reporting. I don't run any backend that receives your prompts, files, keys, or sessions.

  • Local data. Config, API keys, sessions, memory, agents, skills, audit logs, and usage stats are stored locally under ~/.aictl/, with API keys in your OS keychain when available. Delete that directory to remove everything.
  • LLM providers. Prompts and conversation context go straight to the provider you choose (for example OpenAI, Anthropic, Google, xAI, Mistral, DeepSeek, Kimi, or Z.ai), under that provider's own privacy policy. Local models (Ollama, GGUF, MLX) keep everything on your machine. Built-in redaction can mask secrets and personal data before a request leaves your machine.
  • Tools you enable. Tools such as web search, URL fetching, geolocation, and maps contact third-party services (for example DuckDuckGo, Firecrawl, or OpenStreetMap) only when the agent calls them. MCP servers and plugins you install run under their own terms.
  • Update and catalogue checks. The CLI and server fetch a version file from GitHub (raw.githubusercontent.com) to tell you about new releases. Browsing or pulling remote agents and skills, and reading the roadmap, also fetches from GitHub. These requests carry no personal data beyond what any HTTP request reveals, such as your IP address, and are subject to GitHub's privacy statement.
  • Model downloads. Downloading local models or the voice / NER models fetches files from Hugging Face, under Hugging Face's privacy policy.
  • aictl-server. When you self-host the server, you are the operator of whatever it logs. Nothing is sent to me.

The website (aictl.app)

  • Analytics. The site uses DataFast to count page views and see referrers, country, browser, and device type in aggregate. It may set first-party identifiers to tell visits apart. It isn't used for advertising, and I don't sell or share the data.
  • Fonts. Fonts are loaded from Google Fonts, which means your browser sends a request, including your IP address, to Google. See Google's privacy policy.
  • Hosting. Like any website, the hosting provider may keep standard server logs (IP address, user agent, requested URL, time) for security and operations.
  • Downloads. Release binaries are served from GitHub Releases, and the install script fetches them from there.
  • Email. If you email me, I keep your message and address only to reply and handle your request, such as a commercial license.

Legal basis (where GDPR applies): legitimate interest in running and improving the website (analytics, hosting logs) and in answering your messages.

Your rights

If you are in the EU/EEA or a similar jurisdiction, you can ask to access, correct, delete, or restrict processing of your personal data, or object to it. Email piotr@wittchen.io. You can also lodge a complaint with your local data protection authority. You can block analytics at any time with a content blocker or by disabling JavaScript; the site works without it.

Changes

If this policy changes, the updated version will be posted on this page with a new date. The full history is in the git log.
